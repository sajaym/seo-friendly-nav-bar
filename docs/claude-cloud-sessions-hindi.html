Claude Cloud Sessions क्या हैं?

एकदम आसान हिंदी में, नए लोगों के लिए

1. एक लाइन में

Claude Cloud Session = इंटरनेट पर चलने वाला एक अलग कंप्यूटर (container), जिसमें आपका GitHub वाला कोड डाउनलोड होता है, और Claude उसमें बैठकर आपके लिए कोड लिखता, चलाता और टेस्ट करता है। आपके अपने लैपटॉप पर कुछ भी इंस्टॉल करने की ज़रूरत नहीं।

2. यह कैसे काम करता है (पूरा सफ़र)

आपका कोड GitHub पर→ आप claude.ai/code पर session शुरू करते हैं→ Cloud में नया कंप्यूटर बनता है, कोड उसमें clone होता है→ आप हिंदी/English में बताते हैं क्या चाहिए→ Claude कोड लिखता है, commit करता है, GitHub पर push करता है→ आप अपने लैपटॉप पर pull करके देखते हैं

3. ज़रूरी शब्द

शब्दमतलब (आसान भाषा)
SessionClaude के साथ एक काम की बातचीत। हर session को अपना cloud कंप्यूटर मिलता है।
Containerवह अस्थायी (temporary) cloud कंप्यूटर। काम खत्म होने पर या कुछ देर बेकार रहने पर यह मिट जाता है। इसलिए जो भी काम बचाना है, उसे GitHub पर push करना ज़रूरी है।
EnvironmentContainer की सेटिंग: कौन-सी वेबसाइटें खुल सकती हैं, कौन-से टूल इंस्टॉल होंगे, कौन-से secret keys मिलेंगे।
Branchकोड की एक अलग "कॉपी-लाइन"। Claude आमतौर पर claude/... नाम की branch पर काम करता है ताकि आपका main कोड सुरक्षित रहे।
PushCloud से बदलाव GitHub पर भेजना।
PullGitHub से बदलाव अपने लैपटॉप पर लाना।
Pull Request (PR)"मेरी branch के बदलाव main में मिला दो" वाली request। आप GitHub पर देखकर merge कर सकते हैं।

4. Cloud session में Claude क्या-क्या कर सकता है?

  • फ़ाइलें पढ़ना, बनाना, बदलना
  • Terminal commands चलाना (npm, python, tests वगैरह)
  • Browser खोलकर वेबसाइट/एप का screenshot लेना
  • Git commit और push करना
  • GitHub पर PR बनाना, CI की गलतियाँ ठीक करना

5. क्या नहीं कर सकता?

  • आपके लैपटॉप की फ़ाइलों को सीधे नहीं छू सकता। आपके लैपटॉप तक कोड सिर्फ GitHub के रास्ते आता है।
  • Container मिटने के बाद उसमें रखी बिना-push की चीज़ें वापस नहीं आतीं।
  • Environment की network policy जिन वेबसाइटों को रोकती है, उन्हें नहीं खोल सकता।

6. $100 क्रेडिट कैसे समझदारी से इस्तेमाल करें

  • एक session = एक साफ़ काम। जैसे "navbar को mobile-friendly बनाओ"। बहुत छोटे-छोटे सवाल लैपटॉप पर खुद ही कर लें।
  • साफ़ बताएँ क्या चाहिए। जितना साफ़ बताएँगे, उतने कम round लगेंगे, उतने कम credits खर्च।
  • Session खत्म होने पर push ज़रूर हो। हमेशा पूछें: "commit करके push कर दो"।
  • PR बनवाना है तो साफ़ कहें "PR बना दो", वरना Claude सिर्फ branch push करता है।
  • बड़े repo में बार-बार पूरा कोड पढ़वाना महँगा है, इसलिए फ़ाइल का नाम बताकर पूछें।

7. पहली बार शुरू करने के steps

  1. GitHub अकाउंट बनाएँ और अपना code एक repository में डालें (HTML गाइड में पूरा तरीका है)।
  2. claude.ai/code खोलें, GitHub connect करें, repository को allow करें।
  3. "New session" दबाएँ, repository चुनें, और अपना काम लिखें। जैसे:
    index.html में navbar को mobile पर hamburger menu बना दो, फिर commit करके push करो
  4. Claude काम खत्म करे तो branch का नाम नोट करें (जैसे claude/amazing-franklin-607q2j)।
  5. लैपटॉप पर: git fetch origin फिर git checkout claude/amazing-franklin-607q2j और फ़ाइल खोलकर देखें।
  6. पसंद आए तो GitHub पर PR खोलकर main में merge करें।

8. Local vs Cloud: कब क्या?

कोड चलाकर अपनी आँख से देखनालैपटॉप (pull करके)
GitHub पर PR, CI ठीक करनाClaude cloud session
