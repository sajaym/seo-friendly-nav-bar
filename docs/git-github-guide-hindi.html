0. पूरी तस्वीर एक नज़र में

तीन जगहें हैं। हर जगह कोड की एक कॉपी रहती है:
  1. आपका लैपटॉप (local)
  2. GitHub (इंटरनेट पर आपकी repository, यह "बीच का डाकघर" है)
  3. Claude का cloud कंप्यूटर (session के दौरान)
लैपटॉप और Claude कभी सीधे बात नहीं करते। दोनों GitHub के ज़रिये कोड भेजते और लेते हैं।
लैपटॉप: folder बनाया, कोड लिखा
↓ git push
GitHub: repository में कोड पहुँचा
↓ session शुरू (clone अपने आप)
Claude cloud: कोड लिखा, commit, push
↓ git pull / checkout
लैपटॉप: चलाकर देखा, edit किया
↓ git push … और यही चक्र चलता रहता है

1. एक बार की तैयारी

1.1 Install करें

  • Git: git-scm.com/downloads से। Windows पर "Git Bash" भी साथ आता है।
  • VS Code: code.visualstudio.com से। इसमें built-in terminal है।
  • GitHub account: github.com पर Sign up।

1.2 Git को अपना नाम बताएँ (सिर्फ एक बार)

git config --global user.name "Apna Naam"
git config --global user.email "apna@email.com"

1.3 GitHub से login (सिर्फ एक बार)

सबसे आसान तरीका GitHub CLI है:

winget install GitHub.cli      # Windows
brew install gh                # Mac
gh auth login                  # फिर browser में login कर दें

इसके बाद push/pull पर password नहीं माँगेगा।

2. लैपटॉप पर folder बनाना और git शुरू करना

# 1. folder बनाएँ और उसमें जाएँ
mkdir mera-project
cd mera-project

# 2. इस folder को git से "देखना" शुरू करवाएँ
git init

# 3. कोई फ़ाइल बनाएँ (VS Code में या command से)
echo "<h1>Namaste</h1>" > index.html

# 4. git को बताएँ कौन-सी फ़ाइलें save करनी हैं
git add .

# 5. एक "save point" (commit) बनाएँ
git commit -m "pehla commit"
समझें: git add = "इन फ़ाइलों को अगले save में शामिल करो"। git commit = "save point बनाओ, नाम के साथ"। Commit सिर्फ लैपटॉप पर होता है, GitHub पर अभी कुछ नहीं गया।

3. GitHub पर repository बनाना और कोड डालना

तरीका A: gh से (सबसे आसान)

gh repo create mera-project --public --source=. --push

बस। Repository बन गई और कोड ऊपर चला गया।

तरीका B: website से

  1. github.com पर + → New repository → नाम mera-project → Create।
  2. फिर terminal में:
git branch -M main
git remote add origin https://github.com/APKA-USERNAME/mera-project.git
git push -u origin main
remote = GitHub वाली कॉपी का पता। origin उसका nickname है। push = लैपटॉप से GitHub पर भेजो।

4. Claude cloud session से कोड लिखवाना

  1. claude.ai/code खोलें। GitHub connect करें और अपनी repository को allow करें।
  2. New session → repository चुनें mera-project।
  3. साफ़-साफ़ काम लिखें। उदाहरण:
"index.html में एक responsive navbar बनाओ जिसमें Home, About, Contact links हों। Mobile पर hamburger menu हो। CSS को style.css में रखो। काम होने पर commit करके push कर दो।"
  1. Claude काम करेगा और एक branch पर push करेगा, जैसे claude/amazing-franklin-607q2j। यह नाम session के आख़िर में बताया जाता है। नोट कर लें।
याद रखें: Claude आपके main को सीधे नहीं बदलता। वह अलग branch पर काम करता है, ताकि आप पहले देख लें, फिर मिलाएँ।

5. Claude का कोड लैपटॉप पर लाना और चलाना

cd mera-project

# GitHub से नई branches की जानकारी लाओ
git fetch origin

# Claude वाली branch पर जाओ (नाम अपना वाला डालें)
git checkout claude/amazing-franklin-607q2j

अब VS Code में फ़ाइलें देखें। HTML project है तो index.html पर double-click करके browser में खोलें, या VS Code का "Live Server" extension लगाएँ।

Node/Python project हो तो वही चलाएँ जो README में लिखा हो, जैसे npm install और npm run dev।

fetch = सिर्फ जानकारी लाओ। checkout = उस branch की फ़ाइलें folder में दिखाओ। pull = fetch + अभी वाली branch में मिलाओ।

6. लैपटॉप पर खुद edit करके फिर GitHub पर डालना

मान लीजिए आप उसी branch पर हैं और आपने रंग बदला। अब:

git status                      # क्या-क्या बदला, देख लो
git add .
git commit -m "navbar ka color badla"
git push

पहली बार किसी नई branch पर push करना हो तो:

git push -u origin BRANCH-KA-NAAM

7. फिर से Claude को देना (चक्र दोहराना)

आपका push GitHub पर पहुँच गया। अब फिर से claude.ai/code पर जाएँ, वही session खोलें (या नया बनाएँ) और कहें:

"मैंने branch claude/amazing-franklin-607q2j पर color बदला है। उसे pull करो, फिर navbar में एक search box जोड़ो, और push कर दो।"

Claude cloud में git pull करके आपका बदलाव ले लेगा, काम करेगा, push करेगा। आप फिर step 5 दोहराएँ: git pull।

सुनहरा नियम: किसी भी तरफ़ काम शुरू करने से पहले git pull, और काम खत्म होने पर git push। इससे दोनों तरफ़ की कॉपी एक जैसी रहती है और टकराव (conflict) नहीं होता।

8. Branch और PR: main में मिलाना

जब Claude वाली branch का काम पसंद आ जाए, उसे main में मिलाना है। दो तरीके:

तरीका A: GitHub पर Pull Request (सलाह यही है)

  1. github.com पर repository खोलें। ऊपर पीला बैनर दिखेगा "Compare & pull request" → दबाएँ।
  2. Title लिखें, Create pull request।
  3. "Files changed" tab में बदलाव देखें। ठीक लगे तो Merge pull request → Confirm।

या Claude से ही कह दें: "इस branch का PR बना दो"।

तरीका B: terminal से

git checkout main
git pull
git merge claude/amazing-franklin-607q2j
git push

Merge के बाद लैपटॉप को ताज़ा करें

git checkout main
git pull

10. आम गलतियाँ और उनका इलाज

दिक्कतक्या करें
push पर "rejected" आता हैपहले git pull करें, फिर git push। मतलब GitHub पर कुछ नया है जो आपके पास नहीं था।
"CONFLICT" लिखा आ गयाफ़ाइल खोलें, <<<<<<< और >>>>>>> के बीच दोनों versions दिखेंगे। जो रखना है रखें, बाकी मिटाएँ, फिर git add . और git commit। या Claude से कहें "conflict resolve कर दो"।
Claude वाली branch दिख ही नहीं रहीgit fetch origin चलाएँ, फिर git branch -a।
गलती से main पर edit कर दियाgit stash → git checkout -b nayi-branch → git stash pop। बदलाव नई branch पर आ जाएँगे।
Claude session में काम हुआ पर push नहीं हुआSession मिटने से पहले कहें "अभी commit करके push करो"। Cloud container अस्थायी है।
Password बार-बार माँगता हैgh auth login एक बार कर लें।
सबसे ज़रूरी बात: कुछ बिगड़ता नहीं। Git हर commit याद रखता है, और GitHub पर कॉपी सुरक्षित रहती है। डरे बिना try करें। अटकें तो Claude session में पूरा error paste करके पूछ लें।
